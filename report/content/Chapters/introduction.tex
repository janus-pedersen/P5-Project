\section{Introduction}
\textbf{Problem statement:}

How can IoT technologies be used to automatically register and locate a company's mobile assets in order to reduce losses and time spent dealing with misplaced or missing equipment?

\textbf{Research questions:}
\begin{itemize}
    \item  Which technologies are suitable for automatically identifying and registering mobile assets inside a vehicle?
    \item How can the need for manual user interaction be minimized while maintaining reliable and accurate asset registration?
    \item How can data from local sensors be processed and synchronized with a cloud-based system?
    \item How can the system identify missing or misplaced assets and present this information in a useful way to the user?
    \item What technologies can be used to send data from the local setup to the central cloud?
\end{itemize}
